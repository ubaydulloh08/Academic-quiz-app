# Academic Quiz App

This is an intellectual quiz game designed to test advanced academic knowledge.

## Features
- 100 challenging academic questions.
- Auto-resizing dynamic background.
- Continuous background music system.

## How to Play
1. Download the ZIP archive to your computer.
2. Extract the files from the archive.
3. Run the application file.
